# Documentation

## Structure

- **permanent/** - Architectural documents, RFCs, specifications that persist
- **sessions/** - Session documents, HANDOFF files for context transfer between chat sessions
- **temp/** - Temporary files, research, drafts

## Key Documents

| Document | Description |
|----------|-------------|
| [prd.md](permanent/prd.md) | Product Requirements Document |
| [design.md](permanent/design.md) | UI/UX Design System |
| [specs.md](permanent/specs.md) | Technical Specifications |
| [tasks.md](permanent/tasks.md) | Development Roadmap & Tasks |
| [security.md](permanent/security.md) | Security Guidelines |
| [setup.md](permanent/setup.md) | Development Setup Guide |

## Session Workflow

1. Start session → Read latest HANDOFF doc
2. Work on tasks → Update tasks.md
3. End session → Create HANDOFF doc for next session

### HANDOFF Naming Convention
`HANDOFF_YYYY-MM-DD_brief-context.md`
